# 内部代号映射（仅供追溯，不构成对外语义）

本仓的 `I*` / `修正N` / `iN` 是**实现批次、修订与取证编号**，不是对外术语。对外文档/工具描述请用功能名；
本文件只用于把旧文档与 `redproof/` 里的编号对回功能。术语定义见 [../glossary.md](../glossary.md)。

## 取证编号（`iN`，对应 `redproof/`）

`iN` 是红证/标定证据的批次编号，例如 `i5`（表头长度）、`i7`（工具描述）、
`i9`（短查询内容量闸门）、`i10`（闸门回显）、`i11`（`GATE_MARGIN` 标定）、`i12`（路径守卫口径）。
证据文件仍以 `redproof/iN-*.txt` 命名（**文件名不改**，避免破坏可复现性）。引用时说明证据内容，编号仅作定位。
